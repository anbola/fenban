# 智能分班·积分均衡版 (Smart Class Divider)

> 基于「蛇形分班 + 模拟退火 + 多轮精修」的成绩均衡分班工具，与「成绩核算系统 v1.64」积分算法口径完全一致。

一个**纯前端、单文件 HTML** 的智能分班工具：上传学生成绩 → 自动均衡分班 → 导出 Excel 名单与统计报表。
所有计算在浏览器本地完成，**零后端、零数据上传**，适合学校内网或离线使用。

| 特性 | 说明 |
| --- | --- |


在 **Settings → Pages → Custom domain** 填写你的域名，并在域名解析商添加 CNAME 记录指向 `<你的用户名>.github.io`。

## 🧮 算法概要

```
总积分 = Σ(各科积分)
各科积分 = 人均分积分(max-normalize × 50)
        + A 档积分(前 25%, max-normalize × 20)
        + B 档积分(前 60%, max-normalize × 30)
档位线 = FenbanCore.findGradeLine(分数序列, 总人数, 阈值%)  // 同分不拆
```

### 优化目标（按重要性排序）

1. **班级人数差 ≤ 1**（硬约束）
2. **单科均分极差最小**（首要目标，各科均分 / A / B / A+B 档 / 学困人数差 ≤ 1，可整除时压向 0）
3. **单科动态平衡**（A 多则 B 少、A+B 多则人均分稍低、A+B 多则学困生多）
4. **班级总积分均衡**（次要目标，在单科均衡前提下再平衡，受同分不拆约束理论下限 ~0.7~6 分）
5. **性别比例均衡**（硬约束，构造期保证）

### 精修链

```
countRepair → steepestDescent → countRepair
    → rangePolish → complementaryPolish
    → totalScorePolish(25 轮, 顶 2 / 底 2 班搜索, 阈值 0.05)
    → countRepair → totalScorePolish(15 轮)
    → countRepair(200 轮兜底)
```

`totalScorePolish` 在最高分班与最低分班之间做同性别交换；若无改进则尝试次高 / 次低班对，确保逼近理论下限。

## ⚠️ 注意事项

1. **首次运行**：自动清空 LocalStorage 缓存数据（如有遗留测试数据）。
2. **导入覆盖**：每次上传 XLSX 默认**覆盖**软件内已有数据，不会追加。
3. **算法保证**：当 A / B 档人数因「同分不拆」而不可整除时，总积分极差存在先天下限（通常 0.7~6 分），无法压到 0。这是 25% / 60% 阈值 + 同分不拆规则共同决定的，不是 bug。
4. **浏览器兼容**：Chrome / Edge / Firefox 最新版均可；不支持 IE。
5. **离线使用**：CDN 资源需要联网；如需完全离线，把 `xlsx.full.min.js` 下载到本地并修改 HTML 中的 `<script src>` 即可。

## 🙋 常见问题

**Q：为什么总积分极差压不到 0？**
A：A / B 档人数因「同分不拆」存在先天不可整除（如 100 人 5 班，A 档 25 人 / 5 班 = 5，整除；但更多班级数 / 学生数场景下会出现余数），导致 A 档 / B 档积分在班级间存在最小整数差。这是规则决定的，不是算法缺陷。

**Q：可以修改档位比例（25% / 60%）吗？**
A：可以，但需要**同时修改成绩核算系统 v1.64 的对应参数**，否则分班系统与核算系统口径不一致，会导致看板显示与实际核算分数对不上。

**Q：代码能不能完全加密？**
A：当前采用「被动拦截 + 透明源码」策略，方便学校信息技术老师后续维护。如果需要更强的保护，建议部署在内网 + 域名限制访问，而非客户端加密。
