📋 丹凤三小·智能均衡分班系统 - 系统自述

系统名称：丹凤三小·智能均衡分班系统 - 2026v3

开发背景：本系统由AI辅助开发，专为丹凤县第三小学均衡分班需求设计，融合两套分班算法优势，经多轮迭代优化而成。

技术栈：纯HTML+CSS+JS单文件架构，零后端依赖。localStorage持久化存储，SheetJS处理Excel导入导出，Font Awesome图标库，Canvas绘制统计图表。

核心目标：100%公平、绝对均衡、班级人数差≤1、A+B档之和差≤1、同名/谐音学生不分同班、所有指标方差最小化。

一、数据规范

1. 性别根据身份证第17位自动判断（奇=男，偶=女），自动填充性别选择框，也可手动选择覆盖。

2. 身份证号为选填项，导入时强制设为文本格式防止Excel精度丢失（后几位变0的问题）。

3. 模板下载和上传均为XLSX格式，身份证列预设为文本格式。

4. 导入时用SheetJS的cellText选项+列格式强制转换，确保身份证号完整保留。

5. 支持手动添加、批量导入、演示数据生成三种数据录入方式。

二、算法强制规范

1. 人数绝对均衡：各班人数差 ≤ 1，evaluate中人数差>1施加极大惩罚(50000×差值)。

2. A+B档之和差 ≤ 1：evaluate中增加abSumVar惩罚，enforceAll中swapCategory(AB合并)强制修正。

3. 等级划分算法——按单科分别计算（核心）：

重要：A档、B档、学困生均按每个单科分别计算，而非按总分计算。

- 五门科目分别独立进行等级划分；

- 每门科目独立计算A档(25%)、B档(60%)、学困(10%)的理论人数和分数线；

- 均衡评价时统计各班各科目A/B/学困的总人次；

4. 同名/谐音打散：内置400+汉字拼音映射表，将姓名转为拼音键进行比对，同名或谐音学生尽量分到不同班级。

5. 算法流程：①锁定保护 → ②按性别蛇形分层初分(男女生绝对均衡) → ③多重启模拟退火 → ④定向计数修复(A/B/A+B/学困人数极差≤1) → ⑤最速下降精调 → ⑥软指标极差精修 → ⑦定向互补微调(A+B多则人均分稍低 / A档多则B档少 / A+B多则学困多) → ⑧总分专项微调(压制总分最高班) → ⑨总积分极差≤0.5验收，不达标自动换种子重新分班（多结果选最优）。

6. 单科优先（v3.8 核心）：各科 A档、纯B档、A+B档、学困 人数极差均≤1（可整除时压向0）；单科均分极差最小化（首要目标）；A+B 和为主导权重——极差最小，可整除时压向0、不可整除停在1；A与B反向互补（A多则B少，保证A+B和均衡）；A+B多则学困生多（同向，差生与优等生均衡）；班级总积分均衡为次要目标（在单科均衡前提下再平衡）。硬约束：人数差≤1、男女生绝对相等(构造保证)、单科A/纯B/A+B/学困人数极差≤1。差距很小无法调整时自然收敛、不强行破坏其它均衡。

三、权重体系

• 班级人数：100（硬约束：人数差≤1）

• A+B之和：100（主导，极差最小；可整除压向0） | A档生：100 | B档生：100（A多则B少，反向互补）

• 各科均分：100（最优先目标） | 总分：100

• 同名/谐音：100（打散到不同班级）

• 学困生：100（极差最小；与A+B同向：A+B多则学困多） | 性别：100（硬约束：男女生绝对均衡） | 班干部：100 | 特殊生：100

四、交互功能

1. 拖动交换：拖动学生到目标班级，自动匹配总分+各科综合成绩最接近的学生交换，交换后自动执行enforceAll修正。

2. 锁定/解锁：指定班级的学生自动锁定，锁定学生不参与算法分配和拖动交换。

3. 三种视图：卡片视图、紧凑视图、表格视图，满足不同展示需求。

4. 导出功能：分班结果导出为XLSX（含总表和分班表），均衡统计报表导出。

五、系统禁忌

1. 禁止人数差＞1。2. 禁止A+B档之和差＞1。3. 禁止锁定学生可拖动。

4. 禁止虚假数据。5. 班干部均衡默认不勾选。6. 首次运行自动清空旧数据。

7. 同名/谐音打散默认勾选，可通过均衡条件取消。
